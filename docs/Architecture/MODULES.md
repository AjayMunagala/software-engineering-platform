# Module Map

## Version 1

1. Repository Scanner — traverse a repository safely and collect facts.
2. Manifest Readers — parse supported dependency and project manifests.
3. Language Detector — determine languages from files and manifests.
4. Project Classifier — identify frameworks, build systems, and test tools.
5. Report Writer — emit JSON and human-readable reports.

## Future modules
