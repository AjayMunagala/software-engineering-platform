# Milestones

## M0 — Design baseline

Vision, scope, architecture, requirements, decisions, and Repository Scanner design reviewed for consistency.

## M1 — Scanner specification complete

Requirements, report format, internal flow, fixtures, and acceptance tests are approved. No production implementation is required for this milestone.

## M2 — Scanner implementation

The scanner produces validated reports for representative Go, React/TypeScript, and SQL fixture repositories.

## M3 — Repository intelligence

Syntax parsing, symbols, imports, and dependency relationships are queryable.

## M4 — Evidence-based engineering assistance

Investigation, minimal patch proposals, and validation are integrated behind explicit safety controls.
