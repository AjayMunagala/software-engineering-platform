# Competitor Analysis Plan

The goal is to understand the market, not replicate products. Study Cursor, GitHub Copilot, Claude Code, OpenAI Codex, Sourcegraph Cody, Windsurf, Continue, and Aider.

For each product, record:

- Repository-context approach and limits.
- How it displays evidence and uncertainty.
- Whether it supports planning, edits, validation, and review.
- Privacy and local-development options.
- Strengths, failure modes, and useful design lessons.

This document is a research template. Conclusions require dated, primary-source evidence before they guide product decisions.
