# GoPackageIdentityInventory Changelog

## 1.0.0 — Release Candidate

- Defined immutable module, workspace, vendor, replacement, and unmanaged
  resolution contexts.
- Added deterministic location-aware `PackageIdentityProof` values.
- Froze `go-package-proof-id/v1` golden-vector behavior.

- Added strict enum JSON round-tripping and a detached immutable JSON view.
- Validated deterministic output, repository boundaries, cancellation,
  coverage, benchmarks, and race safety.
