| Capability | Status |
|---|---|
| Digest-verified source authorization | Supported |
| Repository-boundary enforcement | Supported |
| Package/file/function/lexical scopes | Supported |
| Top-level and local declarations | Supported |
| Unicode and generics | Supported |
| Receiver binding | Supported |
| Local type relations | Supported |
| Same-package and cross-file references | Supported |
| Proof-backed local imports | Supported |
| Named, blank, dot, and default imports | Supported |
| Evidence-derived interface checks | Supported when evidence is complete |
| Explicit unresolved/ambiguous/external states | Supported |
| Stable IDs, ordering, and JSON enums | Supported |
| Immutable typed and detached JSON views | Supported |
| Deterministic relationship/diagnostic limits | Supported |
| Compiler build-context selection | Deferred |
| External dependency importer | Deferred |
| Call/control/data-flow graphs | Out of scope |
| AI, network, repository tools, or source edits | Forbidden |
