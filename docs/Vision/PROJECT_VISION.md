# Project Vision

## Working name

Aegis CodeMind. The name is provisional and can be changed without changing the product direction.

## Vision

Build a trusted AI software engineer that understands software systems before it recommends changes. It should operate like a careful senior engineer: gather evidence, investigate causes, make minimal changes, and verify results.

## Problem

Many coding assistants generate plausible code without sufficient repository context. They can miss architecture, configuration, dependency relationships, history, logs, and tests. This causes guesses, broad rewrites, and unverified fixes.

## Differentiator

The platform treats the language model as one replaceable component. Repository intelligence, evidence collection, reasoning, validation, and safety controls are first-class product capabilities.

## Long-term success

Given a failure such as “the Login API returns HTTP 500 after yesterday’s merge,” the platform can inspect the repository, relevant changes, logs, configuration, schema, and tests; identify the root cause; create a minimal patch; validate it; and explain the evidence behind the result.

## Non-negotiables

The platform must not present guesses as facts, make unsafe changes silently, or sacrifice architectural correctness for fast code generation.
