# ADR 0001: Go for the Core Backend

## Status

Proposed.

## Decision

Use Go for core local tooling and backend services.

## Rationale

Go provides straightforward cross-platform binaries, filesystem tooling, concurrency, and a reliable standard library.

## Alternatives

TypeScript and Python are viable, but they are not selected as the core backend direction: TypeScript is reserved for the UI, and Python for AI-oriented services.
